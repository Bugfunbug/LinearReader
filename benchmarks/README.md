## Benchmarks
This directory houses all benchmarking data I have collected for LinearReader. Benchmarks were 
collected for LinearReader versions `1.1.0`, `1.2.0`, and `1.3.0`. Benchmarks for older versions 
can be found under the `archive/` directory.

See each directory for notes regarding that versions benchmarks.

Also, don't compare between loaders. These benchmarks are not meant to show whether Forge, Fabric, 
or NeoForge is better than the other loaders.
